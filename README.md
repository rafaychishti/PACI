# PACI

**A public engineering journal documenting my transition from full-stack developer to AI Engineer — through the PACI AI Specialization, from Python fundamentals to AI Systems Engineering.**

This is not a course-notes repository. It's a record of what was built, how it was built, and why — structured so anyone can browse it and reconstruct the path, phase by phase, project by project.

For the full mission, timeline, phase objectives, and engineering principles behind this repo, see **[roadmap.md](./roadmap.md)**.

---

## About

I'm enrolled in the **PACI AI Specialization**, an 18-month structured curriculum covering nine phases — from programming foundations through applied AI systems engineering. This repository is where that curriculum gets turned into practice: notes, experiments, portfolio projects, and progress logs, all committed as the work happens rather than reconstructed afterward.

The target is to complete the program on an accelerated timeline (see [roadmap.md](./roadmap.md#accelerated-learning-strategy) for the strategy behind that), while holding every phase to a portfolio-quality bar — not just "completed," but "built, documented, and defensible."

---

## Curriculum Overview

The table below reflects the official PACI AI Specialization structure. Personal pacing and accelerated targets are tracked separately in [roadmap.md](./roadmap.md#timeline-overview).

| Phase | Official Timeline | Focus | Core Module(s) |
|---|---|---|---|
| 01 | Months 1–3 | Programming Foundation | Python Programming Fundamentals |
| 02 | Months 4–5 | Data Preparation & Numerical Computing | Numerical Computing with Arrays · Data Preparation and Analysis |
| 03 | Month 6 | Structured Data Systems | Structured Data Querying |
| 04 | Months 7–10 | Machine Learning Backbone | Machine Learning Foundations |
| 05 | Months 11–12 | Predictive Modeling Specialization | Regression Modeling and Evaluation · Classification Modeling and Evaluation |
| 06 | Months 13–14 | Applied AI Implementation | Applied AI Practicum |
| 07 | Months 15–16 | Deep Learning Systems | Deep Learning Systems |
| 08 | Month 17 | Computer Vision Deployment | Computer Vision Deployment |
| 09 | Month 18 | AI Systems Engineering | AI Systems Engineering |

**What each phase is building toward:**

- **01 — Programming Foundation:** Python fluency — control flow, functions, OOP, core data structures, debugging, and file handling as reusable, well-organized code rather than scripts.
- **02 — Data Preparation & Numerical Computing:** Scientific Python — arrays, vectorized computation, data cleaning, exploratory analysis, and time-series basics.
- **03 — Structured Data Systems:** SQL for analytics and AI work — filtering, aggregation, joins, and relational thinking.
- **04 — Machine Learning Backbone:** The core ML phase — statistics, probability, feature engineering, supervised and unsupervised learning, and structured model evaluation.
- **05 — Predictive Modeling Specialization:** Applied regression and classification, with emphasis on model comparison and metrics (precision, recall, F1, ROC-AUC).
- **06 — Applied AI Implementation:** Turning theory into portfolio-grade projects across forecasting, NLP, recommendation, and other applied problem settings.
- **07 — Deep Learning Systems:** Neural networks, optimization, CNNs, RNNs, transfer learning, and transformer intuition, built with PyTorch.
- **08 — Computer Vision Deployment:** Object detection, segmentation, tracking, custom dataset training, and deployment-oriented thinking.
- **09 — AI Systems Engineering:** The capstone phase — LLMs, retrieval-augmented generation, vector databases, agent workflows, and evaluation for real AI applications.

## Repository Structure

```
PACI/
├── README.md                          # This file — repo overview and navigation
├── roadmap.md                         # Mission, strategy, timeline, standards, principles
├── phases/                            # One folder per curriculum phase
│   ├── phase-01-programming-foundation/
│   ├── phase-02-data-preparation/
│   ├── phase-03-structured-data/
│   ├── phase-04-machine-learning/
│   ├── phase-05-predictive-modeling/
│   ├── phase-06-applied-ai/
│   ├── phase-07-deep-learning/
│   ├── phase-08-computer-vision/
│   └── phase-09-ai-systems-engineering/
├── projects/                          # Standalone portfolio-grade projects
├── notes/                             # Concept write-ups and reference notes
├── assets/                            # Diagrams, images, and supporting media
└── progress/                          # Weekly logs and phase retrospectives
```

**Folder conventions:**

- **`phases/phase-XX-.../`** — exercises, experiments, and study artifacts tied directly to that phase's curriculum. Each phase folder holds its own short README summarizing what was covered and what it led to.
- **`projects/`** — the portfolio-quality deliverables referenced in `roadmap.md`, promoted out of a phase folder once they're complete and documented well enough to stand alone.
- **`notes/`** — durable reference material (concepts, cheat-sheets, write-ups) that isn't tied to a single phase or project.
- **`assets/`** — diagrams, architecture sketches, screenshots, and other media referenced from notes, project READMEs, or this file.
- **`progress/`** — the weekly logs and phase retrospectives described in [roadmap.md](./roadmap.md#progress-philosophy). This is where actual pacing (vs. the plan) is tracked honestly.

## How to Navigate This Repository

- Start with **[roadmap.md](./roadmap.md)** for the why and the plan.
- Browse **`phases/`** to see the raw learning process for a given phase.
- Browse **`projects/`** for the portfolio-grade output — this is the fastest way to evaluate the work without reading the process behind it.
- Check **`progress/`** for the current pace, what's shipped, and what's next.
